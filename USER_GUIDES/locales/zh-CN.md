# CLARYEL RemoteOps — 简明指南

RemoteOps 是一种免费、开源的方式，可通过 AI 聊天中的语音或文字管理您自己的 Windows、Linux 或 macOS 电脑。

## 您可以做什么

- 安装、更新或删除软件；
- 配置经过批准的电脑设置；
- 检查电脑和系统健康状态；
- 修复问题，并在验证失败时回滚。

## 简单使用

1. 打开您喜欢的 AI 聊天工具。
2. 说出或输入希望实现的结果。
3. 在计划清楚时阅读并批准简短方案。
4. RemoteOps 执行已登记的操作并验证结果，或者进行回滚。

## 您需要什么

- **AI 聊天工具。** ChatGPT 已经过内部测试。其他 AI 聊天工具有已记录的接入方式，但尚未与 RemoteOps 完成测试。
- **CLARYEL RemoteOps。** 安全层免费且开源。

## 平台状态

Linux 和 macOS 工作流程已经过内部测试，但稳定的公开证据仍待发布。Windows 初始化和方案结构已受支持；特权 Windows 适配器和公开回滚证据正在准备中。

## 安全规则

不要批准您不理解的更改。要求更简单的说明和清晰可见的恢复路径。
