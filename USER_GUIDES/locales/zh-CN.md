# CLARYEL RemoteOps — 简明指南

RemoteOps 可帮助您管理自己的 Linux 或 macOS 电脑，而无需记住大量系统管理命令。

## 四个步骤

1. **连接**一个私有配置仓库。
2. **描述**您希望实现的结果。
3. **批准**前检查影响、风险、备份和回滚方案。
4. **验证**系统健康状态。检查失败时必须恢复到最近的可用状态。

## 保持私密

切勿把密码、令牌、私钥、恢复代码、个人文件、提示词、对话、日志或备份放入公共仓库。电脑专属配置应保存在您的私有仓库中；密钥和其他秘密值应保存在受保护的本地存储中。

## AI 状态

ChatGPT 已在 CLARYEL 内部流程中测试。Claude、Gemini、Perplexity 和 Grok 已记录可行路径，但尚未与 RemoteOps 完成测试。ChatGPT 免费方案不保证提供 GitHub 访问，也不把可写控制宣传为普遍免费的功能。

## 安全规则

如果您不理解某项拟议更改，请不要批准。要求更简单的说明和清晰可见的回滚路径。
