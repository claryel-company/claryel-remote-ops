# CLARYEL RemoteOps — स्थापना और निजी सेटअप

RemoteOps आपके अपने Windows, Ubuntu/Linux या macOS कंप्यूटर को आपकी चुनी हुई AI चैट के माध्यम से प्रबंधित करता है।

## 1. इंस्टॉल करें

- [Windows इंस्टॉलर](../../installers/install-windows.ps1)
- [macOS इंस्टॉलर](../../installers/install-macos.sh)
- [Ubuntu इंस्टॉलर](../../installers/install-ubuntu.sh)

डाउनलोड की गई फ़ाइल चलाएँ। RemoteOps आपके उपयोगकर्ता प्रोफ़ाइल में इंस्टॉल होता है, निजी स्थानीय कार्यक्षेत्र बनाता है और ऑपरेटिंग सिस्टम की सुरक्षा बंद नहीं करता।

## 2. अपना व्यक्तिगत Private रिपॉज़िटरी बनाएँ

GitHub CLI इंस्टॉल करें, `gh auth login` चलाएँ और फिर इंस्टॉलर द्वारा दिखाया गया कमांड चलाएँ:

```text
remoteops connect --path आपका-निजी-पथ --create-private remoteops-my-computer
```

रिपॉज़िटरी आपके GitHub खाते में `Private` दृश्यता के साथ बनती है। RemoteOps इसे सार्वजनिक नहीं करता और सहयोगी नहीं जोड़ता।

Private का अर्थ है जनता से छिपा हुआ। फिर भी आप, आपके द्वारा स्पष्ट रूप से अधिकृत व्यक्ति या ऐप और सेवा संचालक के रूप में GitHub पहुँच सकते हैं। खाते को passkey या दो-कारक प्रमाणीकरण से सुरक्षित करें।

Git में कभी भी पासवर्ड, टोकन, निजी कुंजी, रिकवरी कोड, व्यक्तिगत फ़ाइलें, चैट, कच्चे लॉग, डेटाबेस या बैकअप न रखें।

## 3. गोपनीयता जाँचें

```text
remoteops privacy-check --path आपका-निजी-पथ
```

तभी आगे बढ़ें जब परिणाम में `"ok": true`, `"visibility": "PRIVATE"` और कोई निष्कर्ष न हो।

## 4. ChatGPT कनेक्ट करें

1. **ChatGPT > Settings > Apps > GitHub** खोलें।
2. **Only select repositories** चुनें।
3. केवल `remoteops-my-computer` चुनें।
4. स्वीकृति से पहले अनुमतियाँ जाँचें।
5. **Settings > Data Controls > Improve the model for everyone** की समीक्षा करें।
6. चैट में कभी भी रहस्य या व्यक्तिगत फ़ाइलें पेस्ट न करें।

GitHub ऐप की उपलब्धता और लिखने की क्षमता ChatGPT योजना और मोड पर निर्भर करती है। केवल पढ़ने वाला कनेक्शन बदलाव लागू नहीं कर सकता।

## संचार सीमा

RemoteOps GitHub से केवल निजी रिपॉज़िटरी जोड़ने या सिंक करने पर, ChatGPT से केवल आपके उपयोग पर और पैकेज स्रोतों से केवल स्वीकृत सॉफ़्टवेयर कार्यों के लिए संपर्क करता है। इंस्टॉलर विज्ञापन या असंबंधित एनालिटिक्स नहीं जोड़ते।
