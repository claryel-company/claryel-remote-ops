# CLARYEL RemoteOps — απλός οδηγός

Το RemoteOps σας βοηθά να διαχειρίζεστε τον δικό σας υπολογιστή Linux ή macOS χωρίς να απομνημονεύετε εντολές διαχείρισης.

## Τέσσερα βήματα

1. **Συνδέστε** ένα ιδιωτικό αποθετήριο ρυθμίσεων.
2. **Περιγράψτε** με απλά λόγια το αποτέλεσμα που θέλετε.
3. **Εγκρίνετε** το σχέδιο μόνο αφού ελέγξετε την επίπτωση, τον κίνδυνο, το αντίγραφο ασφαλείας και την επαναφορά.
4. **Επαληθεύστε** την υγεία του συστήματος. Μια αποτυχημένη δοκιμή πρέπει να επαναφέρει την τελευταία σωστή κατάσταση.

## Διατηρήστε τα ιδιωτικά

Μην αποθηκεύετε ποτέ στο δημόσιο αποθετήριο κωδικούς, token, ιδιωτικά κλειδιά, κωδικούς ανάκτησης, προσωπικά αρχεία, προτροπές, συνομιλίες, αρχεία καταγραφής ή αντίγραφα ασφαλείας. Η ειδική ρύθμιση του υπολογιστή ανήκει στο ιδιωτικό αποθετήριο και τα μυστικά παραμένουν σε προστατευμένο τοπικό χώρο.

## Κατάσταση AI

Το ChatGPT έχει δοκιμαστεί εσωτερικά στη ροή CLARYEL. Claude, Gemini, Perplexity και Grok είναι τεκμηριωμένα αλλά δεν έχουν δοκιμαστεί με το RemoteOps. Η πρόσβαση GitHub στο ChatGPT Free δεν είναι εγγυημένη και η εγγραφή δεν παρουσιάζεται ως καθολική δωρεάν λειτουργία.

## Ασφαλής κανόνας

Αν δεν καταλαβαίνετε μια προτεινόμενη αλλαγή, μην την εγκρίνετε. Ζητήστε απλούστερη εξήγηση και σαφή διαδρομή επαναφοράς.
