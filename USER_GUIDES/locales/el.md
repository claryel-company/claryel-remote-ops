# CLARYEL RemoteOps — εγκατάσταση και ιδιωτική ρύθμιση

Το RemoteOps διαχειρίζεται τον δικό σας υπολογιστή Windows, Ubuntu/Linux ή macOS μέσω της συνομιλίας AI που επιλέγετε.

## 1. Εγκατάσταση

- [Εγκαταστάτης Windows](../../installers/install-windows.ps1)
- [Εγκαταστάτης macOS](../../installers/install-macos.sh)
- [Εγκαταστάτης Ubuntu](../../installers/install-ubuntu.sh)

Εκτελέστε το αρχείο που κατεβάσατε. Το RemoteOps εγκαθίσταται στο προφίλ χρήστη, δημιουργεί ιδιωτικό τοπικό χώρο εργασίας και δεν απενεργοποιεί την ασφάλεια του λειτουργικού συστήματος.

## 2. Δημιουργήστε το προσωπικό σας αποθετήριο Private

Εγκαταστήστε το GitHub CLI, εκτελέστε `gh auth login` και μετά την εντολή που εμφανίζει ο εγκαταστάτης:

```text
remoteops connect --path Η-ΙΔΙΩΤΙΚΗ-ΔΙΑΔΡΟΜΗ-ΣΑΣ --create-private remoteops-o-ypologistis-mou
```

Το αποθετήριο δημιουργείται στον λογαριασμό GitHub σας με ορατότητα `Private`. Το RemoteOps δεν το δημοσιοποιεί και δεν προσθέτει συνεργάτες.

Private σημαίνει κρυφό από το κοινό. Πρόσβαση μπορούν ακόμη να έχουν εσείς, άτομα ή εφαρμογές που εξουσιοδοτείτε ρητά και το GitHub ως πάροχος της υπηρεσίας. Προστατεύστε τον λογαριασμό με passkey ή έλεγχο δύο παραγόντων.

Μην αποθηκεύετε ποτέ στο Git κωδικούς, token, κλειδιά, κωδικούς ανάκτησης, προσωπικά αρχεία, συνομιλίες, ακατέργαστα logs, βάσεις δεδομένων ή αντίγραφα ασφαλείας.

## 3. Έλεγχος ιδιωτικότητας

```text
remoteops privacy-check --path Η-ΙΔΙΩΤΙΚΗ-ΔΙΑΔΡΟΜΗ-ΣΑΣ
```

Συνεχίστε μόνο αν εμφανίζονται `"ok": true`, `"visibility": "PRIVATE"` και κανένα εύρημα.

## 4. Σύνδεση ChatGPT

1. Ανοίξτε **ChatGPT > Ρυθμίσεις > Apps > GitHub**.
2. Επιλέξτε **Μόνο επιλεγμένα αποθετήρια**.
3. Επιλέξτε μόνο `remoteops-o-ypologistis-mou`.
4. Ελέγξτε τα δικαιώματα πριν την έγκριση.
5. Ελέγξτε **Ρυθμίσεις > Έλεγχοι δεδομένων > Βελτίωση του μοντέλου για όλους**.
6. Μην επικολλάτε ποτέ μυστικά ή προσωπικά αρχεία στη συνομιλία.

Η διαθεσιμότητα της εφαρμογής GitHub και η δυνατότητα εγγραφής εξαρτώνται από το πρόγραμμα και τη λειτουργία ChatGPT. Μια σύνδεση μόνο για ανάγνωση δεν μπορεί να εφαρμόσει αλλαγές.

## Όριο επικοινωνίας

Το RemoteOps επικοινωνεί με το GitHub μόνο όταν συνδέετε ή συγχρονίζετε το ιδιωτικό αποθετήριο, με το ChatGPT μόνο όταν το χρησιμοποιείτε και με πηγές πακέτων μόνο για εγκεκριμένες λειτουργίες. Οι εγκαταστάτες δεν προσθέτουν διαφημίσεις ή ξένα analytics.
