# CLARYEL RemoteOps — دليل مبسّط

RemoteOps طريقة مجانية ومفتوحة المصدر لإدارة حاسوب Windows أو Linux أو macOS بالصوت أو الكتابة داخل محادثة ذكاء اصطناعي.

## ما الذي يمكنك فعله

- تثبيت البرامج أو تحديثها أو إزالتها؛
- إعداد خيارات الحاسوب المعتمدة؛
- فحص حالة الحاسوب والنظام؛
- إصلاح المشكلات والتراجع عند فشل التحقق.

## استخدام بسيط

1. افتح محادثة الذكاء الاصطناعي التي تفضلها.
2. قل أو اكتب النتيجة المطلوبة.
3. اقرأ الخطة القصيرة ووافق عليها عندما تكون واضحة.
4. ينفذ RemoteOps إجراءً مسجلاً ويتحقق من النتيجة أو يتراجع.

## ما الذي تحتاجه

- **محادثة ذكاء اصطناعي.** تم اختبار ChatGPT داخلياً. للمحادثات الأخرى مسارات موثقة لكنها لم تُختبر مع RemoteOps.
- **CLARYEL RemoteOps.** طبقة الأمان مجانية ومفتوحة المصدر.

## حالة المنصات

تم اختبار مسارات Linux وmacOS داخلياً، ولا تزال الأدلة العامة المستقرة مطلوبة. إعداد Windows والمخططات مدعومان؛ ويجري تجهيز مهايئ Windows ذي الصلاحيات وأدلة التراجع العامة.

## قاعدة آمنة

لا توافق على تغيير لا تفهمه. اطلب شرحاً أبسط ومسار استعادة واضحاً.
