# CLARYEL RemoteOps — دليل مبسّط

يساعدك RemoteOps على إدارة حاسوب Linux أو macOS الخاص بك دون حفظ أوامر إدارة النظام.

## أربع خطوات

1. **اربط** مستودع إعدادات خاصاً.
2. **صف** النتيجة المطلوبة بكلمات بسيطة.
3. **وافق** على الخطة بعد مراجعة التأثير والمخاطر والنسخة الاحتياطية وطريقة التراجع.
4. **تحقق** من سلامة النظام. عند فشل الفحص يجب استعادة آخر حالة سليمة.

## حافظ على الخصوصية

لا تضع أبداً كلمات المرور أو الرموز أو المفاتيح الخاصة أو رموز الاسترداد أو الملفات الشخصية أو التعليمات أو المحادثات أو السجلات أو النسخ الاحتياطية في المستودع العام. إعدادات الحاسوب الخاصة بك تكون في المستودع الخاص، وتبقى القيم السرية في تخزين محلي محمي.

## حالة أنظمة الذكاء الاصطناعي

تم اختبار ChatGPT داخلياً ضمن مسار CLARYEL. تم توثيق مسارات Claude وGemini وPerplexity وGrok، لكنها لم تُختبر مع RemoteOps. لا يوجد ضمان لتوفر GitHub في خطة ChatGPT المجانية، ولا يتم تقديم التحكم بالكتابة كميزة مجانية عامة.
