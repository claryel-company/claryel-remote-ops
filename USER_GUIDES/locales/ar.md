# CLARYEL RemoteOps — التثبيت والإعداد الخاص

يدير RemoteOps جهازك الشخصي بنظام Windows أو Ubuntu/Linux أو macOS من خلال محادثة الذكاء الاصطناعي التي تختارها.

## 1. التثبيت

- [مثبّت Windows](../../installers/install-windows.ps1)
- [مثبّت macOS](../../installers/install-macos.sh)
- [مثبّت Ubuntu](../../installers/install-ubuntu.sh)

شغّل الملف الذي نزّلته. يُثبَّت RemoteOps داخل ملف المستخدم، وينشئ مساحة عمل محلية خاصة، ولا يعطّل حماية نظام التشغيل.

## 2. إنشاء مستودعك الشخصي Private

ثبّت GitHub CLI، وشغّل `gh auth login`، ثم نفّذ الأمر الذي يعرضه المثبّت:

```text
remoteops connect --path مسارك-الخاص --create-private remoteops-my-computer
```

يُنشأ المستودع في حساب GitHub الخاص بك برؤية `Private`. لا يجعله RemoteOps عاماً ولا يضيف متعاونين.

Private يعني مخفياً عن الجمهور. لكنك أنت، والأشخاص أو التطبيقات التي تفوضها صراحة، وGitHub بصفته مشغل الخدمة يمكنهم الوصول وفق الصلاحيات. احمِ الحساب بمفتاح مرور أو مصادقة ثنائية.

لا تحفظ أبداً في Git كلمات المرور أو الرموز أو المفاتيح الخاصة أو رموز الاسترداد أو الملفات الشخصية أو المحادثات أو السجلات الخام أو قواعد البيانات أو النسخ الاحتياطية.

## 3. التحقق من الخصوصية

```text
remoteops privacy-check --path مسارك-الخاص
```

تابع فقط عندما تظهر `"ok": true` و`"visibility": "PRIVATE"` ولا توجد نتائج تحذيرية.

## 4. توصيل ChatGPT

1. افتح **ChatGPT > الإعدادات > Apps > GitHub**.
2. اختر **المستودعات المحددة فقط**.
3. حدد فقط `remoteops-my-computer`.
4. راجع الصلاحيات قبل الموافقة.
5. راجع **الإعدادات > عناصر التحكم في البيانات > تحسين النموذج للجميع**.
6. لا تلصق أسراراً أو ملفات شخصية في المحادثة.

يعتمد توفر تطبيق GitHub والقدرة على الكتابة على خطة ChatGPT ووضع الاستخدام. الاتصال للقراءة فقط لا يمكنه تطبيق تغييرات.

## حدود الاتصال

يتصل RemoteOps بـ GitHub فقط عند ربط أو مزامنة مستودعك الخاص، وبـ ChatGPT فقط عندما تختار استخدامه، وبمصادر الحزم فقط للعمليات البرمجية التي توافق عليها. لا تضيف أدوات التثبيت إعلانات أو تحليلات غير مرتبطة.
