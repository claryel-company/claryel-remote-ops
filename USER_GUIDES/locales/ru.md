# CLARYEL RemoteOps — установка и приватная настройка

RemoteOps управляет вашим собственным компьютером с Windows, Ubuntu/Linux или macOS через выбранный вами ИИ-чат.

## 1. Установите

- [Установщик Windows](../../installers/install-windows.ps1)
- [Установщик macOS](../../installers/install-macos.sh)
- [Установщик Ubuntu](../../installers/install-ubuntu.sh)

Запустите скачанный файл. RemoteOps устанавливается в профиль вашего пользователя, создаёт приватное локальное рабочее пространство и не отключает защиту операционной системы.

## 2. Создайте свой личный репозиторий Private

Установите GitHub CLI, выполните `gh auth login`, затем команду, которую покажет установщик:

```text
remoteops connect --path ВАШ-ПРИВАТНЫЙ-ПУТЬ --create-private remoteops-my-computer
```

Репозиторий создаётся в вашем аккаунте GitHub с видимостью `Private`. RemoteOps не делает его публичным и не добавляет участников.

Private означает, что репозиторий скрыт от публики. Доступ по разрешениям всё равно имеете вы, явно разрешённые вами люди или приложения и GitHub как оператор сервиса. Защитите аккаунт ключом доступа или двухфакторной аутентификацией.

Никогда не храните в Git пароли, токены, приватные ключи, коды восстановления, личные файлы, переписку, необработанные журналы, базы данных или резервные копии.

## 3. Проверьте приватность

```text
remoteops privacy-check --path ВАШ-ПРИВАТНЫЙ-ПУТЬ
```

Продолжайте только когда результат показывает `"ok": true`, `"visibility": "PRIVATE"` и пустой список найденных проблем.

## 4. Подключите ChatGPT

1. Откройте **ChatGPT > Настройки > Apps > GitHub**.
2. Выберите **Только выбранные репозитории**.
3. Выберите только `remoteops-my-computer`.
4. Проверьте разрешения до подтверждения.
5. Проверьте **Настройки > Управление данными > Улучшать модель для всех**.
6. Никогда не вставляйте секреты или личные файлы в чат.

Доступность приложения GitHub и возможность записи зависят от тарифа и режима ChatGPT. Подключение только для чтения не может применять изменения.

## Граница внешних соединений

RemoteOps обращается к GitHub только когда вы подключаете или синхронизируете личный приватный репозиторий, к ChatGPT — только когда вы сами его используете, а к источникам пакетов — только для одобренной установки или обновления программ. Установщики не добавляют рекламу или постороннюю аналитику.
