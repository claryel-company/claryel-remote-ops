# CLARYEL RemoteOps — встановлення та приватне налаштування

RemoteOps керує вашим власним комп’ютером Windows, Ubuntu/Linux або macOS через обраний вами чат ШІ.

## 1. Встановіть

- [Інсталятор Windows](../../installers/install-windows.ps1)
- [Інсталятор macOS](../../installers/install-macos.sh)
- [Інсталятор Ubuntu](../../installers/install-ubuntu.sh)

Запустіть завантажений файл. RemoteOps встановлюється у профіль користувача, створює приватний локальний робочий простір і не вимикає захист операційної системи.

## 2. Створіть особистий репозиторій Private

Встановіть GitHub CLI, виконайте `gh auth login`, а потім команду, яку покаже інсталятор:

```text
remoteops connect --path ВАШ-ПРИВАТНИЙ-ШЛЯХ --create-private remoteops-miy-kompyuter
```

Репозиторій створюється у вашому обліковому записі GitHub з видимістю `Private`. RemoteOps не робить його публічним і не додає співавторів.

Private означає прихований від публіки. Доступ усе одно маєте ви, явно дозволені вами люди або застосунки та GitHub як оператор сервісу. Захистіть обліковий запис ключем доступу або двофакторною автентифікацією.

Ніколи не зберігайте в Git паролі, токени, приватні ключі, коди відновлення, особисті файли, чати, сирі журнали, бази даних або резервні копії.

## 3. Перевірте приватність

```text
remoteops privacy-check --path ВАШ-ПРИВАТНИЙ-ШЛЯХ
```

Продовжуйте лише якщо результат показує `"ok": true`, `"visibility": "PRIVATE"` і відсутність знахідок.

## 4. Підключіть ChatGPT

1. Відкрийте **ChatGPT > Налаштування > Apps > GitHub**.
2. Оберіть **Лише вибрані репозиторії**.
3. Виберіть тільки `remoteops-miy-kompyuter`.
4. Перевірте дозволи перед підтвердженням.
5. Перевірте **Налаштування > Контроль даних > Покращувати модель для всіх**.
6. Ніколи не вставляйте секрети чи особисті файли в чат.

Доступність застосунку GitHub і можливість запису залежать від тарифу та режиму ChatGPT. Підключення лише для читання не може застосовувати зміни.

## Межа комунікації

RemoteOps звертається до GitHub лише коли ви підключаєте або синхронізуєте приватний репозиторій, до ChatGPT лише коли ви ним користуєтеся, а до джерел пакетів лише для схвалених операцій. Інсталятори не додають рекламу чи сторонню аналітику.
