# CLARYEL RemoteOps — простий посібник

RemoteOps допомагає керувати власним комп’ютером Linux або macOS без запам’ятовування команд системного адміністрування.

## Чотири кроки

1. **Підключіть** приватний репозиторій конфігурації.
2. **Опишіть** простими словами бажаний результат.
3. **Підтвердьте** план лише після перевірки впливу, ризику, резервної копії та відкату.
4. **Перевірте** стан системи. Невдала перевірка повинна відновити останній працездатний стан.

## Зберігайте приватність

Ніколи не додавайте до публічного репозиторію паролі, токени, приватні ключі, коди відновлення, особисті файли, промпти, розмови, журнали або резервні копії. Конфігурація конкретного комп’ютера належить приватному репозиторію; секретні значення залишаються у захищеному локальному сховищі.
