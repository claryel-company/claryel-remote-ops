# CLARYEL RemoteOps — простий посібник

RemoteOps — безкоштовний проєкт із відкритим кодом для керування комп’ютером Windows, Linux або macOS голосом чи текстом через ШІ-чат.

## Що можна робити

- встановлювати, оновлювати або видаляти програми;
- налаштовувати дозволені параметри комп’ютера;
- перевіряти стан комп’ютера й системи;
- виправляти проблеми та виконувати відкат, якщо перевірка не пройдена.

## Просте використання

1. Відкрийте зручний ШІ-чат.
2. Скажіть або напишіть бажаний результат.
3. Прочитайте й підтвердьте короткий план, коли він зрозумілий.
4. RemoteOps виконує зареєстровану дію та перевіряє результат або робить відкат.

## Що потрібно

- **ШІ-чат.** ChatGPT протестовано внутрішньо. Інші ШІ-чати мають задокументовані шляхи, але не протестовані з RemoteOps.
- **CLARYEL RemoteOps.** Захисний рівень безкоштовний і має відкритий код.

## Стан платформ

Робочі процеси Linux і macOS протестовано внутрішньо; стабільні публічні докази ще потрібні. Підготовка та схеми Windows підтримуються; привілейований адаптер Windows і публічні докази відкату готуються.

## Безпечне правило

Не підтверджуйте зміну, якої не розумієте. Попросіть простіше пояснення та видимий шлях відновлення.
